# 💰 Tip Calculator

A simple web-based Tip Calculator built using **HTML**, **CSS**, and **JavaScript**. This app helps users quickly calculate the **tip amount per person** and the **total amount per person** based on the bill amount, tip percentage, and number of people sharing the bill.

## 🚀 Features

- Input for **bill amount**
- Input for **tip percentage**
- Input for **number of people**
- Calculates:
  - **Tip per person**
  - **Total per person** (including tip)
- Simple and responsive UI
